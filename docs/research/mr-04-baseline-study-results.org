#+TITLE: MR-04: Baseline FX Mean-Reversion Phenomenon Study Results
#+STARTUP: overview indent

* Purpose

This document records the first real run of the MR-01 baseline
mean-reversion event study (issue #281, MR-04) against Trader's
canonical historical data, using the MR-02
(=indicator.SMA=/=RollingStdDev=/=ZScore=) and MR-03
(=analysis.RunEventStudy=) capabilities exactly as
=docs/research/mr-01-experiment-definition.org= specifies, and states
an explicit research conclusion. It is a results record, not a durable
architecture decision — it carries no ADR number.

No Trader package code changed to produce this result. The analyzer
(=analysis.RunEventStudy=), the primitives it is built on
(=indicator.ZScore=), and the real canonical =marketdata.Manager= data
path it reads through were all already complete and merged (issues
#279, #280). This issue is purely running that already-built,
already-tested capability against real data and recording what it
found.

* Reproduction

** Git commit

Commit ~c777b25~ on ~main~ (the tip after PR #291 merged), Go
~go1.25.1 linux/amd64~.

** Runner

A throwaway Go program, =research-runs/mr-04/main.go= (gitignored,
like =research-runs/ema-11= before it — not part of any Trader
package, adds no new public API, imports only already-merged public
Trader packages). It:

1. Opens a real =*marketdata.Manager= against the persistent canonical
   store (=/srv/trading/data/canonical=) and raw OANDA archive
   (=/srv/trading/data/raw/oanda=).
2. For each of MR-01's pinned 10-pair basket, and for each of the two
   periods below, resolves the instrument, plans/builds any missing
   canonical partitions from the already-present local raw archive
   (no live OANDA credentials used or required — every raw partition
   both periods touch already existed on disk), and reads the full H1
   bar series via =Manager.Bars=.
3. Runs =analysis.RunEventStudy= with MR-01's pinned parameters
   (=ZScorePeriod: 20=, =Horizons: analysis.MR01Horizons()=) against
   each pair/period's bars.
4. Pools every pair's =ForwardReturns= per (period, bucket, horizon)
   cell into cross-instrument aggregate statistics, using the same
   mean/median/population-stddev/fraction-toward-mean formulas
   =analysis.BucketHorizonStats= itself uses.

** Configuration

Every instrument uses the identical, unmodified MR-01 configuration —
no per-pair parameter changes, per MR-04's own acceptance criteria:

| Parameter        | Value                                             |
|-------------------+----------------------------------------------------|
| Bar interval      | H1                                                |
| Rolling window N  | 20 bars                                           |
| Z-score buckets   | MR-01's fixed 5 buckets (extreme/moderate/neutral) |
| Forward horizons  | 4h, 12h, 24h, 48h                                 |
| Instrument basket | EUR/USD, GBP/USD, USD/JPY, USD/CHF, AUD/USD, NZD/USD, USD/CAD, EUR/GBP, EUR/CHF, AUD/NZD |

** Data spans and development/out-of-sample labeling

Per MR-01's requirement to distinguish already-examined data from a
genuinely untouched period:

- *Development (2015-01-01 to 2025-01-01, exclusive)*: the same
  2015-2025 span this session's own prior ad hoc exploratory analysis
  (Hurst exponent, autocorrelation, N-sigma conditional forward-return
  checks) already examined, and the same span EMA-11 used. Results
  from this period are *not* out-of-sample evidence and are labeled as
  such throughout.
- *Holdout (2005-01-01 to 2015-01-01, exclusive)*: the real OANDA raw
  archive extends back to January 2005 for every one of the 10 basket
  pairs (confirmed directly against the archive before choosing this
  boundary), and no prior exploratory analysis this session examined
  this range. Ten years is enough to satisfy MR-01's "sufficient
  pre-2015 history" condition, so this period is used as the initial
  genuine holdout set MR-01 asks for, rather than labeling the whole
  study developmental.

Bar counts actually read (per pair, per period) ranged 62,165-62,197
observations in development and 64,451-64,776 in holdout (holdout is a
calendar year longer); every pair/period combination produced well
over MR-01's 30-observation minimum in every bucket — the smallest
bucket cell pooled across all 10 pairs had 41,088 observations (see
Results below), so no cell in this study falls under the
insufficient-evidence threshold.

** Statistical magnitude (extreme-positive cell, both periods)

A rough single-sample t-statistic (mean / (stddev / sqrt(n)), no
multiple-comparisons correction) for the extreme-positive bucket,
which produced this study's largest and most horizon-consistent
effect:

| Period      | 4h    | 12h   | 24h   | 48h  |
|-------------+-------+-------+-------+------|
| Development |  -4.9 |  -8.6 |  -5.6 | -6.3 |
| Holdout     |  -4.1 |  -4.3 |  +0.2 | +0.7 |

Development shows a consistently significant negative drift at every
horizon. Holdout shows a comparably significant negative drift at 4h
and 12h, but the effect is statistically indistinguishable from zero
— and nominally reverses sign — at 24h and 48h.

* Required Measurements

** Does the effect strengthen with |Z|| (monotonicity)?

Inconsistently. On the positive-Z side, extreme deviations show a
larger-magnitude subsequent negative return than moderate deviations
in development (for example 48h: extreme -0.024% vs. moderate -0.008%)
— the direction MR-01's hypothesis predicts. On the negative-Z side,
the pattern does not hold: moderate-negative's mean return is
frequently as large as or larger than extreme-negative's (development
48h: moderate +0.010% vs. extreme +0.004%), the opposite of what
"stronger reversion at greater deviation" would predict.

** Development vs. out-of-sample behavior

The one horizon-consistent, cross-sectionally broad effect found
(extreme-positive short-horizon reversion) is present in both periods
at 4h and 12h, but its magnitude is smaller in holdout, and it does
not survive to 24h/48h in holdout — where development shows its
*strongest* effect (largest magnitude, highest |t|). This is the
opposite of what growing confidence in a real phenomenon would look
like: the holdout period does not confirm development's own strongest
result.

** Asymmetry between positive and negative deviations

Clear and consistent across both periods: downside (negative-Z)
deviations show at most a weak, inconsistent, largely
statistically-insignificant tendency to revert. Upside (positive-Z)
deviations show a real, cross-sectionally broad (7-9 of 10 pairs),
short-horizon (4h-12h) negative drift in both periods — the single
most substantive finding of this study, though not one MR-01's
hypothesis predicted as one-sided.

* Interpretation

** Classification: Weak / Inconclusive

Per MR-01's own interpretation criteria: "Some expected behavior is
present, but it is inconsistent across instruments, horizons,
directions, or periods." That is precisely what this study found:

- The overall symmetric hypothesis (both tails revert, monotonically)
  is *not* supported: the negative-Z side shows no reliable reversion
  in either period, and monotonicity fails there entirely.
- A real, statistically distinguishable, cross-sectionally broad
  effect exists on the positive-Z side, but only at short horizons
  (4h-12h), and it does not hold at the longer horizons (24h/48h) in
  the untouched holdout period, where development showed its
  *strongest* result. A pattern that is strongest precisely where it
  is least tested (development) and weakest/absent precisely where it
  is genuinely out-of-sample (holdout, long horizons) is the signature
  of overfitting to the already-explored period, not of a robust
  phenomenon.
- USD/JPY consistently runs opposite to the basket majority on the
  positive-Z side in both periods — plausibly related to JPY's
  well-documented carry-trade/trend character — which is itself a
  documented asymmetry rather than noise, but further underscores that
  no single, pair-independent rule is supported.

** Recommendation

Per MR-04's own acceptance criteria: this is not a "Supported" result,
so MR-05 (translating the phenomenon into a minimal trading strategy)
should *not* proceed on the general MR-01 hypothesis (fade any extreme
Z-score deviation, either direction, any horizon). Proceeding to build
and optimize a symmetric mean-reversion strategy on this evidence would
risk optimizing against noise that this study's own holdout period
already shows does not reliably repeat.

The one narrow, documented candidate worth naming — *not* scheduled as
follow-on work, per MR-01/MR-04's shared discipline against tuning
after seeing results — is a short-horizon-only, upside-only,
excluding-JPY-pairs variant, since that is the one slice of this
study's results that showed both cross-sectional breadth and (at least
partial) out-of-sample persistence. Any future investigation of that
narrower candidate should be its own new, separately specified
hypothesis and experiment definition (following MR-01's own template),
not a silent narrowing of this study's already-frozen scope.

* Relationship to Later Issues

MR-05 (translating a supported phenomenon into a minimal trading
strategy) is not authorized to proceed on the general MR-01 hypothesis
by this result. Mean-reversion research work following this issue
should either close out the milestone on this honest negative/weak
result (mirroring EMA-11's own precedent for a milestone that
concludes "not promising, and that is a valid result") or open a new,
narrowly-scoped hypothesis document for the upside-only/short-horizon
candidate specifically, rather than reopening MR-01 through MR-04.
