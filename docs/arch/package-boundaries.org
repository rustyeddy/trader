#+TITLE: Trader Package Boundaries
#+SUBTITLE: The live packages and what each may import (ADR-091)
#+STARTUP: overview indent

The matrix of the earlier, larger runtime (ADR-065) is kept in
=_archive/docs/package-boundaries.org=; it does not describe this tree. This table
is the current one. Each rule marked (test) is an architecture test that fails when
the rule is broken.

| Package | Role | May import (within the module) |
|---------+------+--------------------------------|
| =cmd/trader= | transport: flags, environment, config file | =trader= (the engine, for the backtest run), =service=, =store=, =internal/logging=; the download command still imports =provider/oanda= and =store= directly until it moves behind a service (#641). =build.go= may import only the service, the store and logging (test) |
| =service= | application services | =marketdata/service=, =provider/oanda= only (test) |
| =marketdata/service= | market-data domain service | =marketdata=, =marketdata/internal/canonical=, =num=, =internal/marketdata/layout=, =store=; never a provider or another domain service |
| =marketdata/internal/canonical= | canonical-v2 format and availability rule | =marketdata=, =num=, =layout=, =store=; importable only from =marketdata/= (compiler and test) |
| =marketdata= | public model: =Bar=, =OHLC=, =SourcePartition= | =num= only for the model; the tree may import only =num=, =layout=, =store= and itself (test) |
| =provider/oanda= | raw store, REST client, raw-to-source mapping | =marketdata=, =instrument=, =num=, =internal/logging=, =internal/marketdata/layout=, =store= only (test); never =marketdata/service= |
| =store= | the only data-file I/O | standard library only; no other package calls file functions on data paths (test) |
| =internal/marketdata/layout= | the one data path resolver | standard library only |
| =internal/logging= | structured logging on =log/slog= | standard library; =slog='s global logger is used only by the root engine and =cmd= (test) |
| =num=, =instrument= | exact numbers; instrument identity | =num= has a private fixed-point package (test); =instrument= imports =num= |
| =trader= (module root) | the engine | =marketdata=, =num=, =instrument=; reads no files itself except the scenario loader |

Rules that hold across the table:

- Dependencies point down: transport, application service, domain service, private
  implementation. Domain services do not call each other.
- Only =store= opens, renames or walks data files, and paths are relative to its
  root.
- Only =cmd/trader= reads the environment and the config file; secrets come only
  from the environment (ADR-078).
- =_archive/= is never imported.
