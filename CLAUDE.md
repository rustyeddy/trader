# Claude Code Instructions

Read and follow [AGENTS.md](./AGENTS.md) before working in this repository. It
holds the principles, the layering (ADR-091), the security rules and the working
rules; [docs/CONTRIBUTING.org](docs/CONTRIBUTING.org) holds the issue, branch and
pull-request process.

For any Go test creation or modification, read and follow the Go testing rules in
[docs/workflows/ai-skills.org](docs/workflows/ai-skills.org).

Keep architecture decisions in the issue until the owner approves them. Work is
tracked in GitHub issues (milestone "Market Data" for the data layers); take one
issue at a time.
